# C++ Fundamentals & Systems Practice

A curated collection of clean, well-structured C++ console applications focused on core language mechanics, object-oriented design, and practical problem-solving.

This repository serves as a foundation for building strong programming discipline — emphasizing readable code, modular design, input validation, and clear separation of concerns.

---

## Projects

### 1. Calculator (`1_Calculator/`)
A robust command-line calculator implementing arithmetic operations with proper input handling and error checking.

**Key Focus Areas**
- Clean function decomposition
- Input validation and edge-case handling
- Persistent user interaction loop

### 2. Banking System (`2_BankingSystem/`)
A simple banking simulation demonstrating account management, balance tracking, and transaction logic.

**Key Focus Areas**
- Object-oriented modeling of real-world entities
- Encapsulation of state and behavior
- Basic transaction safety and user feedback

### 3. Tic-Tac-Toe (`3_TicTacToe/`)
A complete two-player Tic-Tac-Toe game with board rendering, win/draw detection, and turn management.

**Key Focus Areas**
- 2D array / board state management
- Game loop architecture
- Win-condition algorithms

### 4. Number Guessing Game (`4_GuessingGame/`)
An interactive guessing game that practices random number generation, user input loops, and feedback systems.

**Key Focus Areas**
- Controlled randomness
- Loop constructs and conditionals
- User experience through clear prompts

---

## Technical Details

- **Language**: Modern C++ (C++17 compatible)
- **Build**: Standard `g++` / any modern C++ compiler
- **Style**: Readable, modular, and beginner-to-intermediate friendly
- **Dependencies**: None (pure standard library)

### Build & Run Example
```bash
# Navigate into any project folder
cd 1_Calculator

# Compile
g++ -std=c++17 -o calculator main.cpp

# Run
./calculator
```
